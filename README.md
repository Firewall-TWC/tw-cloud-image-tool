# TW Images Tool - инструкция пользователя

Сервис для загрузки, хранения и конвертации образов виртуальных дисков TimeWeb.Cloud.
Образ можно загрузить с компьютера или по ссылке, перевести в другой формат
и получить прямую ссылку для скачивания.

**Адрес сервиса:** [img.tw-work.ru](https://img.tw-work.ru)

## Быстрый старт

1. Откройте сервис и войдите по паролю.
2. На вкладке **Загрузка** выберите файл с компьютера или вставьте ссылку.
3. Если нужен другой формат, откройте вкладку **Конвертация**, выберите образ и целевой формат.
4. Следите за ходом работы на вкладке **Активные процессы**.
5. На вкладке **Образы** скопируйте ссылку на готовый файл.

> ⚠️ Образы автоматически удаляются через **3 дня** после загрузки или конвертации.
> Скачайте или используйте их вовремя.

---

## Вход в сервис

- Сервис защищён общим паролем. Узнайте его у администратора.
- После входа пароль не спрашивается **31 день** в этом браузере.
- После 5 неверных попыток вход с вашего IP блокируется на 15 минут.
- Кнопка **Выйти** в правом верхнем углу завершает сессию.

## Загрузка образа с компьютера

**Вкладка «Загрузка» → «С устройства»**

1. Перетащите файл в область загрузки или нажмите на неё и выберите файл.
2. Под областью появится полоса прогресса в процентах.
3. После сообщения «Образ загружен» файл появится на вкладке **Образы**.

**Что важно знать:**
- Максимальный размер файла - **500 ГБ**.
- За раз загружается **один файл**. Если перетащить несколько, загрузится только первый.
- Файл передаётся частями по 32 МБ. При кратковременном обрыве сети часть отправляется повторно (до 3 попыток).
- **Не закрывайте и не обновляйте вкладку браузера**, пока идёт загрузка. Если закрыть страницу, загрузка прервётся и её придётся начать заново.
- Пустые файлы (0 байт) не принимаются.

## Загрузка образа по ссылке

**Вкладка «Загрузка» → «По ссылке»**

1. Вставьте ссылку на файл.
2. Нажмите **Скачать на сервер**.
3. Откроется вкладка **Активные процессы**, где виден ход скачивания.

Скачивание идёт на сервере, поэтому страницу можно закрыть: загрузка продолжится.

**Какие ссылки поддерживаются:**

| Источник | Пример | Комментарий |
|---|---|---|
| Прямая ссылка на файл | `https://example.com/image.qcow2` | Основной вариант |
| S3 / объектное хранилище | `https://s3.twcstorage.ru/.../disk.qcow2` | Работает, в том числе с пробелами и русскими буквами в имени |
| Ссылка с форматом в параметре | `https://host/ID?file=.qcow2` | Формат берётся из `?file=` |
| Яндекс.Диск | `https://disk.yandex.ru/d/XXXX.qcow2` | Допишите расширение в конец ссылки |
| Google Drive | `https://drive.google.com/file/d/ID/view` | Только небольшие публичные файлы |

**Требования к ссылке:**
- ссылка должна вести на **сам файл**, а не на страницу с кнопкой «Скачать»;
- в ссылке должно быть видно расширение (`.qcow2`, `.vmdk`, `.iso` и т.д.);
- доступны только внешние адреса по `http` или `https`, внутренние адреса сети запрещены;
- файл должен быть доступен без авторизации.

Если сервер-источник сообщает настоящее имя файла, образ сохранится под этим именем.

## Конвертация

**Вкладка «Конвертация»**

1. В левом списке выберите исходный образ. В списке только файлы, уже загруженные в хранилище.
2. В правом списке выберите целевой формат.
3. Нажмите **Конвертировать**.
4. Откроется вкладка **Активные процессы** с прогрессом в процентах.

**Правила:**
- Конвертировать в тот же формат нельзя: в списке целевых форматов его нет.
- `raw` и `img` - один и тот же формат, конвертация между ними запрещена.
- **ISO не конвертируется**: это образ файловой системы, а не диска. ISO можно только загрузить и хранить, в списке для конвертации его нет.
- Для `vhd` и `vhdx` создаётся динамический диск, который занимает место только под реальные данные.
- Исходный образ после конвертации **не удаляется**, результат сохраняется рядом отдельным файлом.

**Имя результата:** берётся имя исходника с новым расширением. Если такое имя уже занято, добавляется номер:

```
disk.qcow2 → disk.vmdk
disk.qcow2 → disk(1).vmdk   (если disk.vmdk уже есть)
```

**Очередь.** Число одновременных конвертаций ограничено. Лишние задачи ждут со статусом «В очереди» и запускаются автоматически, когда освобождается место.

**Настройки** (раскрывающийся блок под формой) позволяют изменить число параллельных конвертаций. Новое значение применяется сразу. Меняйте его, только если понимаете нагрузку на сервер.

**Сколько это длится.** Время зависит от размера образа и формата: от нескольких секунд для небольших образов до нескольких часов для сотен гигабайт.

## Образы и ссылки для скачивания

**Вкладка «Образы»**

Здесь все готовые файлы в хранилище: имя, размер и прямая ссылка вида

```
https://img.tw-work.ru/images/имя_образа.формат
```

| Кнопка | Действие |
|---|---|
| Копировать | Копирует ссылку в буфер обмена (кнопка ненадолго подсвечивается зелёным) |
| Удалить | Удаляет образ с сервера после подтверждения. **Действие необратимо** |

Ссылку можно передать коллегам или вставить в панель TimeWeb.Cloud: для скачивания по ней пароль не нужен. Скачивание поддерживает докачку.

Недокачанные и ещё конвертируемые файлы в этом списке не видны. Они появляются только после успешного завершения.

## Активные процессы

**Вкладка «Активные процессы»** состоит из двух таблиц: загрузки по ссылке и процессы конвертации. Таблицы обновляются автоматически каждые 3 секунды.

**Статусы:**

| Статус | Значение |
|---|---|
| Загрузка | Файл скачивается |
| В очереди | Конвертация ждёт свободного места |
| Выполняется | Идёт конвертация |
| Готово | Файл доступен на вкладке «Образы» |
| Ошибка | Процесс завершился неудачно или был отменён |

**Прогресс загрузки по ссылке.** Если источник сообщает размер файла, показываются проценты. Если нет, показывается объём скачанного и индикатор «…».

**Кнопки:**

| Кнопка | Когда доступна | Действие |
|---|---|---|
| Отменить (круг с крестиком) | Пока процесс идёт | Останавливает загрузку или конвертацию и удаляет недописанный файл |
| Убрать (крестик) | После завершения | Убирает запись из списка. Сам образ не удаляется |

**Причина ошибки.** Наведите курсор на статус «Ошибка», и появится подсказка с причиной. При ошибке загрузки также всплывает уведомление в правом нижнем углу.

Если процесс завис (например, сервер перезапускался), в течение нескольких минут он автоматически получит статус «Ошибка». Запустите его заново.

## Хранение и автоудаление

- Образы хранятся **3 дня**, затем удаляются автоматически вместе с записями в списках.
- Файлы, которые сейчас загружаются или конвертируются, не удаляются.
- Занятое и свободное место видно в подвале страницы. Полоса заполнения:
  - синяя - места достаточно;
  - жёлтая - занято больше 75%;
  - красная - занято больше 90%, нужно удалить ненужные образы.

## Частые вопросы

**Появилось «Неподдерживаемый формат».**
Расширение файла не входит в список поддерживаемых, или в ссылке его не видно.
Для Яндекс.Диска допишите в конец ссылки расширение, например `.qcow2`.

**Имя файла изменилось после загрузки.**
Русские буквы переводятся в латиницу, пробелы и спецсимволы заменяются на `_`,
а к занятому имени добавляется номер. Например, `тест образ.qcow2` сохранится как `test_obraz.qcow2`.

**Загрузка с компьютера прервалась с ошибкой сети.**
Проверьте соединение и загрузите файл заново. Не закрывайте вкладку во время загрузки.

**«Сессия истекла, войдите заново».**
Срок входа закончился или вы вышли на другом устройстве. Обновите страницу и введите пароль.

**Конвертация долго стоит «В очереди».**
Все места для конвертации заняты. Задача запустится автоматически, отменять её не нужно.

**Ссылка на образ открывает 404.**
Скорее всего, образ удалили вручную или он пролежал больше 3 дней. Загрузите его снова.

**По ссылке с Google Drive скачался маленький файл или ошибка.**
Для больших файлов Google отдаёт страницу подтверждения вместо файла.
Скачайте файл и загрузите его с компьютера или используйте прямую ссылку.

## Технологический стек

### Бэкенд
- **Python** + **FastAPI** - API и веб-приложение
- **Uvicorn** - ASGI-сервер (за Nginx)
- **SQLAlchemy** + **PyMySQL** - работа с БД
- **MariaDB / MySQL** - база данных
- **Redis** + **RQ** - две очереди фоновых задач: `conversions` и `downloads`
- **qemu-img** - конвертация образов дисков
- **httpx** - стриминговое скачивание по URL с проверкой адресов (SSRF-защита)
- **argon2-cffi** - хеширование пароля
- **itsdangerous** - подпись cookie-сессий

### Фронтенд
- Ванильный **JavaScript**, **HTML** (Jinja2), **CSS** на кастомных переменных
- SVG-иконки, анимации, адаптивная вёрстка в стиле TimeWeb Cloud

### Инфраструктура
- **Debian 13**
- **systemd** - веб-сервис и два пула воркеров
- **cron** - очистка хранилища и сброс зависших процессов
- **Nginx** - реверс-прокси + прямая раздача образов (с поддержкой Range)
- **Let's Encrypt** (certbot) - HTTPS

## Поддерживаемые форматы

| Формат | Ключ qemu-img | Загрузка | Конвертация |
|---|---|:---:|:---:|
| qcow2 | `qcow2` | ✅ | ✅ |
| vmdk | `vmdk` | ✅ | ✅ |
| vhd | `vpc` | ✅ | ✅ |
| vhdx | `vhdx` | ✅ | ✅ |
| vdi | `vdi` | ✅ | ✅ |
| raw / img | `raw` | ✅ | ✅ |
| iso | - | ✅ | ❌ |

> `raw` и `img` - один и тот же формат, конвертация между ними запрещена.
> Для `vhd` и `vhdx` используется `subformat=dynamic`.

## Известные ограничения

- **Яндекс.Диск**: ссылка должна заканчиваться расширением, например
  `https://disk.yandex.ru/d/XXXX.qcow2`. Ссылки без расширения пока отклоняются.
- **Google Drive**: работают только небольшие публичные файлы. Для больших файлов
  Google отдаёт страницу подтверждения, её обход пока не реализован.
- Отмена конвертации в очереди срабатывает сразу, а запущенный `qemu-img`
  останавливается в течение примерно 5 секунд.
